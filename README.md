**Deep Learning-Based Diabetic Retinopathy Detection using ResNet and EfficientNet**

A deep learning project that detects and classifies diabetic retinopathy from retinal fundus images using ResNet and EfficientNet-B0 models. The system classifies images into five stages: No_DR, Mild, Moderate, Severe, and Proliferate_DR. Developed using Python and TensorFlow, the project explores deep learning techniques for automated retinal image analysis and supports the early identification of diabetic retinopathy.
